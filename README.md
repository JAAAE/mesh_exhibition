# 3D Mesh Studio & Exhibition (3D 展覽)

基於 **Three.js** 開發的網頁版 3D 模型展示平臺。介面採用日式侘寂美學風格設計，支援模型瀏覽、網格模式切換、空間距離量測以及 OBJ 檔案匯出。

---

## 核心特色

* **日式侘寂視覺風格**：採用暖木灰、消炭色與和紙白（`#fbfaf7`）作為主色調，打造極簡且專注的瀏覽體驗。
* **九宮格展覽大廳**：直覺的 3x3 矩陣選單，支援動態分頁，輕鬆管理與展示多個 3D 模型作品。
* **雙模式渲染切換**：
  * **模型 + 材質**：完整載入並呈現 3D 模型細節與貼圖（`.mtl`）。
  * **模型網格結構**：一鍵切換至 Wireframe 網格視角。
* **3D 空間距離量測**：在模型表面點選任意兩點，即可即時計算歐幾里得空間距離，並顯示精確的三維坐標 ($x, y, z$)。
* **標準 OBJ 匯出**：支援將目前檢視中的 3D 模型一鍵匯出下載為標準 `.obj` 格式。
* **順暢互動與備援機制**：支援 360 度旋轉、縮放與平移（OrbitControls），若本地資源缺失會自動載入預設模型備援。
